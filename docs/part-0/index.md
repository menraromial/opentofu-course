Le [ch. 1](infrastructure-as-code.mdx) montre, sur un exemple exécuté avec Docker, ce qui sépare un script d’une configuration déclarative, décrit ce que fait OpenTofu à chaque exécution, situe l’outil parmi les autres et raconte d’où vient le projet. Le ch. 2 installe OpenTofu, l’interface en ligne de commande d’AWS et le profil utilisé dans tout le cours, crée une alerte budgétaire et met en place le script qui vérifie qu’aucune ressource ne reste après un TP.
